# Curriculum (one topic per session, end the session with a note in JOURNAL.md)
1. Market microstructure: bid/ask, queue position, adverse selection. Goal: explain why a limit order earns or pays the spread.
2. Execution cost models: spread, slippage, fees, financing. Goal: build a per-trade cost table from primary sources.
3. Position sizing and risk of ruin: Kelly, fractional Kelly, drawdown math. Goal: compute the ruin probability of the FTMO rules for a given edge.
4. Statistics for trading: t-tests with overlapping trades, bootstrap, multiple testing, deflated Sharpe. Goal: write one reusable significance function.
5. Volatility and options basics: implied vs realised, variance risk premium, what a put costs. Goal: say what a risk premium pays and who bears the risk.
6. Behavioural finance: overtrading, disposition effect, base rates of retail performance. Goal: list the three most common self-sabotage patterns and how to measure them.
7. Data quality: tick vs bar data, timezone, DST, survivorship, look-ahead. Goal: write a data-check checklist used by every test.
8. LLM evaluation: contamination, cutoffs, prompt freezing, calibration. Goal: design one calibration test with a Brier baseline.
