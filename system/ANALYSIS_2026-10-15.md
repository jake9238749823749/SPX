# Process review of the forecaster (2026-10-15, before any forecast was made)

## Measured
- ORB on SPXUSD, MES cost, 1 contract:
  - dev 2021-10..2024-12: 335 days, P(net>0) = 0.725, mean net +3.57 bp/day.
  - holdout 2025-01..2026-09: 169 days, P(net>0) = 0.645, mean net -3.35 bp/day.

## Flaws found
1. **Wrong target.** P(net>0) ignores payoff size. Holdout hit rate is still 64%, yet the mean is negative, so a forecaster scored on hit rate can "win" while losing money.
2. **Stale baseline.** P0 = 0.7254 is a dev-period constant. The holdout regime is different. A fixed P0 rewards a forecaster that predicts the old regime.
3. **Forecasting a falsified rule.** Gross per trade was -1.56 bp in holdout. The system forecasts the outcome of a rule that already failed out-of-sample. Its PASS path would still be valid only in the narrow sense that it beats a stale number.
4. **Underpowered verdict.** 120 days (~6 months) detects only a large improvement. A rough estimate: to get a 95% CI narrow enough to detect a 0.02 Brier skill, you need roughly 400 days, not 120. The verdict is likely to be "inconclusive" at 120.
5. **Daily cadence adds little.** One forecast a day, ~130/year, for a question whose answer is already known to be negative out of sample.

## Decision (proposed; needs Jake's approval to rebuild)
- Daily forecaster **paused** (trigger disabled). Nothing is committed against the flawed spec.
- Before any new forecast, the spec must change, logged here:
  - target = expected net bp per day (regression), scored by MSE against a **trailing 120-day mean** baseline, not a fixed constant;
  - verdict needs ~400 scored days, or a pre-registered effect size that 120 can detect;
  - the underlying signal must have positive out-of-sample gross, which ORB currently does not.
- Honest default: ORB has no live signal left. The forecaster is only worth rebuilding if a *different* signal family, with post-cutoff evidence, is chosen first. Otherwise the best use of this process is auditing others' claims (path 5).
