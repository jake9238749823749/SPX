# Repo instructions for every session

## Before doing any work
0. Read `GOAL.md`. The goal is growing a Robinhood account (changed from FTMO on 2026-10-16).
1. Read `learning/KNOWLEDGE.md` in full.
2. Read the last 3 entries of `learning/JOURNAL.md`.
3. Check `system/PROGRESS.md` for the current forecaster state (paused as of 2026-10-15).

## Before ending a session
1. Append a JOURNAL.md entry: what you learned, what you got wrong, the next question.
2. Update KNOWLEDGE.md. Every P entry must cite a file or commit. Demote anything contradicted by new evidence.
3. Commit and push.

## Standing rules
- Pre-registration before data. Holdout opens once, with logged exceptions only.
- No publishing or posting anywhere without Jake's explicit approval.
- Do not schedule or enable any task that makes forecasts without a new pre-registration.
- Robinhood connector: read-only use by default. Every order needs Jake's explicit approval for that order.
